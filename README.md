# ⚡ Reflex

A tiny reaction-time game that runs in your browser. No installs, no accounts.

## How to play
1. Click the big box (or press **Space**).
2. Wait for it to turn **green**.
3. Click as fast as you can!

If you click too early, it counts as a false start. Your best time is saved in your browser.

| Time | Rank |
|------|------|
| < 200 ms | 🐐 Pro gamer |
| < 250 ms | 🔥 Fast |
| < 300 ms | 👍 Solid |
| < 400 ms | 🙂 Average |
| 400+ ms | 🐢 Sleepy |

## ⬇ Download

**[Download Reflex (.zip)](https://github.com/vcecho100-dot/idk/archive/refs/heads/main.zip)**, unzip it, and double-click `index.html`. Works offline.

## 📲 Install as an app
Open **https://vcecho100-dot.github.io/idk/** in Chrome or Edge and click **⬇ Install app** (or the install icon in the address bar). On a phone, use **Add to Home screen**. It gets its own icon and works offline.
