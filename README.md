# 🧊 Model AI

Type what you want, get a simple 3D model. A tiny test app: no installs, no accounts.

> **Test version:** there's no real AI yet. It reads keywords from what you type (shape, color, size, how many) and builds the model from basic shapes. Anything it doesn't recognize becomes a random sculpture (the same words always give the same one).

## How to use
1. Type something like `red car`, `3 green trees`, `big snowman` or `blue robot`.
2. Press **Enter** or click **Generate**.
3. Drag to spin it, scroll to zoom.
4. Click **💾 Save .obj** to download the model. Open it in Blender, Windows 3D Viewer, Godot, etc.

**Shapes:** car, tree, house, snowman, robot, rocket, tower, table, cube, sphere, cylinder, cone, donut, capsule
**Colors:** red, green, blue, yellow, orange, purple, pink, white, black, gray, brown, gold, silver, cyan
**Extras:** `big` / `small`, and a number (`1`–`9` or `one`–`nine`) for how many

## ⬇ Download (Windows app)

**[Download ModelAI.exe](https://github.com/vcecho100-dot/idk/releases/latest/download/ModelAI.exe)**, then double-click it to run. No install needed.

If Windows says "Windows protected your PC", click **More info → Run anyway** (the app isn't code-signed).

Prefer the browser version? **[Download the .zip](https://github.com/vcecho100-dot/idk/archive/refs/heads/main.zip)**, unzip it, and open `index.html` (needs internet the first time to load the 3D engine).

## 📲 Install as an app
Open **https://vcecho100-dot.github.io/idk/** in Chrome or Edge and click **⬇ Install app** (or the install icon in the address bar). On a phone, use **Add to Home screen**.
